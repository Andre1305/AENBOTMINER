# SonarStudio 4.7-Pro-Analysis-test.1

Legado de alta fidelidade, lupa nativa DN/dB digitais relativos, fichas privadas de alvo e correções do cache.

Versão experimental para Windows. Inclui launcher, fontes e os modelos específicos de sonar. Execute `Instalar-SonarStudio.ps1` para instalar o runtime local.

Não inclui gravações, mapas, datasets pessoais, manuais privados, relatórios privados ou chaves. A IA produz candidatos, não identificações certificadas. Amostragem nativa não é precisão de posicionamento. Correções de sobreposição são relativas; não substituem sensores de atitude. A maré precisa de referência vertical compatível.

Validação local: 124 testes aprovados; 26 testes do Viewer reexecutados após ajustes. Comparação pixel a pixel dos cinco filtros legados e das seis paletas. PDFs verificados com AES-256, rejeição de senha incorreta e imagem/metadados incorporados. A lupa mostra DN 0–255 e `20 log10(DN/255)`, explicitamente não calibrados; DN zero tem dB indefinido. A intensidade não determina material. Altura de sombra é uma estimativa com hipóteses e envelope de cenários.

As fichas privadas exigem a chave DPAPI pessoal, que não é distribuída. O computador do proprietário utiliza o runtime de PDF local do Codex; esta dependência não está embutida no ZIP.
