# SonarStudio 4.9-Hybrid-beta.4

- Python GUI e IA mantidos; kernels Numba/LLVM para leitura, alcance e paleta, compilação em segundo plano e fallback legado.
- GPU OpenGL experimental para ajustes de cores; congela/exporta pelo pipeline CPU original quando aplicável.
- DownScan em painel vertical ao lado do SideScan; escala de análise preserva zoom durante navegação e redimensionamento; enquadramento manual de todos os canais.
- Exportar trecho PNG captura os canais visíveis combinados, com legenda opcional do ping selecionado (GPS do barco, profundidade, velocidade e horário).
- C oculta marcador; Ctrl+W salva waypoint GPS do barco; Ctrl+Shift+W marca alvo estimado no SideScan; exportação GPX.
- SonarStudio-Legado.exe permite comparação e recuperação; diagnóstico de encerramentos com código de erro.

Validação local: 142 testes aprovados, ambos os launchers verificados; Rec00001/Rec00002 usados exclusivamente localmente. Janela de 3.000 pings com correção de alcance: aproximadamente 1,5 s na v4.8 para 0,62 s no teste local CPU; não é garantia universal de desempenho. Comparativos de kernels preservaram pixels. LLVM adiciona consumo de memória; GPU usa readback.

ZIP requer Instalar-SonarStudio.ps1/Pixi, internet e runtime Python local. Sem C++/Rust DLL, certificação metrológica ou nova aferição da acurácia da IA. Documentos privados, gravações, coordenadas de levantamentos, chaves e datasets não são publicados.
