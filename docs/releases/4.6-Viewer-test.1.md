# SonarStudio 4.6-Viewer-test.1

Leitura assíncrona, sincronização de canais, régua e sombra com hipóteses, cache de IA.

Versão experimental para Windows. Inclui launcher, fontes e os modelos específicos de sonar. Execute `Instalar-SonarStudio.ps1` para instalar o runtime local.

Não inclui gravações, mapas, datasets pessoais, manuais privados, relatórios privados ou chaves. A IA produz candidatos, não identificações certificadas. Amostragem nativa não é precisão de posicionamento. Correções de sobreposição são relativas; não substituem sensores de atitude. A maré precisa de referência vertical compatível.
